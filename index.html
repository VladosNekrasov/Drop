Первая настройка

Делается один раз. Файлы будут лежать в приватном репозитории на твоём GitHub, а ключ доступа сохранится здесь в зашифрованном виде. Открыть его можно только паролем.

  1. Открой github.com → Fine-grained tokens
  2. Expiration: No expiration (или год). Repository access: All repositories или выбери этот сайт и хранилище
  3. Permissions → Repository → Contents: Read and write. Если хранилища ещё нет, добавь Administration: Read and write
  4. Сгенерируй и вставь токен ниже

Минимум 8 символов. Зашифрованный ключ лежит в открытом репозитории сайта, так что пароль вида 12345678 не годится. Возьми что-то длинное, но запоминаемое.
